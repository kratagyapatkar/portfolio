# Kratagya Patkar — Portfolio

> **Interaction Designer & Vibe Coder** — A premium dark-themed portfolio with custom cursor, scroll-reveal animations, magnetic social links, and tilt-effect project cards.

## ✨ Features

- 🎯 Custom cursor with hover-aware dot + ring
- 📜 Scroll-triggered reveal animations (IntersectionObserver)
- 🧲 Magnetic social link buttons
- 🃏 3D tilt effect on project cards
- 🔄 Rotating status badge ("Open to work" / "Available for hire")
- 📱 Fully responsive with mobile hamburger menu
- 🌌 Featured project: **CineVerse** — autonomous movie discovery universe
- 🎨 Noise texture overlay for premium feel
- ⚡ Pure vanilla HTML/CSS/JS — zero dependencies, instant load

## 🛠 Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Instrument Serif, Space Grotesk, JetBrains Mono)
- Deployed on Vercel
